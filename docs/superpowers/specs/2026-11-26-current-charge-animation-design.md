# 电流与电荷关系动画设计

## 目标

制作一份可离线打开的单页 HTML，帮助初三学生看懂电流与电荷量、时间之间的关系，并用动画呈现电荷定向移动。

## 教学主线

学生先预测：在相同时间内，通过导线某一截面的电荷量变多，电流会怎样变化？页面再让学生播放电荷运动动画、观察截面计数和时间变化，最后归纳 `I = Q / t`。单位说明为 `1 A = 1 C/s`。

## 动画与物理表达

- 主画面是一段导体和固定计数截面；粒子通过截面时，累计电荷量随之更新，计时器记录经过时间，电流读数由累计电荷量除以时间得到。
- 提供正电荷与负电荷两种运动示意。正电荷向右移动时，传统电流向右；负电荷向左移动时，传统电流仍向右。
- 说明金属导体中实际移动的是自由电子；“正电荷向右”用于表达等效的传统电流方向，不表示金属正离子沿导线移动。
- 运动速度可以调整，控制播放、暂停和重播。粒子动画仅作示意，数值和速度之间保持一致的教学模型关系。
- 强调导体传导电流时电荷在移动和重新分布，并未被导体或用电器消耗。

## 页面结构

1. 简短标题与核心提问。
2. 电荷运动动画、方向图例、时间和通过截面的电量计数。
3. 先猜问题及点击后显示的解释。
4. `I = Q / t` 公式和库仑、安培单位卡片。
5. 因果语言总结：单位时间内通过截面的电荷量越多，电流越大。

## 实现约束

- 一个自包含 HTML 文件，内嵌 CSS、SVG/HTML 图形和原生 JavaScript，无外部依赖，断网可用。
- 控件可用键盘操作；布局适配窄屏；动画具有暂停和重播控制。
- 不扩展到完整电路、电源或用电器实验，也不使用水流类比。

## 验收要点

- 正负电荷运动方向和传统电流方向的关系表达正确。
- 公式中的电量、时间和电流在动画里有清晰对应。
- 页面先让学生预测，再揭示解释。
- 动画不会暗示电荷被消耗，且注明金属导体的自由电子模型。
