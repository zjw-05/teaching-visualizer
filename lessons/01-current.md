# 电流是怎样形成的？

**建议用时：** 15 分钟　｜　**核心问题：** 闭合电路里，灯为什么会持续发光？

**配套交互：** [打开电学原理实验室](../index.html#lesson-current)，先预测灯的状态，再切换开关验证。

## 核心问题与误区

常见误区：电流是电池“送出来、经过灯泡后被用掉”的东西。

本课要建立的链条：**电源在两端建立电压 → 电路闭合 → 电荷在导体中定向移动形成电流 → 灯泡把电能转化为光和热。** 电荷在回路中循环，不会被灯泡消耗掉。

## 一页理解图

```text
     电源提供电压（推动作用）
   ┌──────────→──────────┐
   │       传统电流方向 →   │
 [电池]                  [灯泡] → 光、热
   │       ← 电荷回路      │
   └──────────←──────────┘
              开关闭合

闭合回路 + 电源提供电压 → 电荷定向移动 → 持续电流 → 能量转化
```

方向说明：图中实线箭头表示初中常用的**传统电流方向**（外电路中从电源正极经用电器回到负极）。金属导线中的自由电子漂移方向与传统电流相反。灯泡转化的是电能，不是把电荷“吃掉”。

## 先猜一猜

1. 开关断开，灯会持续亮吗？请指出回路在哪里断了。  
   **听什么：** 是否能说出电路不闭合，不能形成持续电流。
2. 把灯泡换到回路另一侧，灯泡会不会“分到更少的电流”？  
   **听什么：** 是否知道单一串联回路各处电流相同，电荷不会在灯泡处消失。

## 动手验证

**材料：** 低压电池盒（1–2 节教学用电池）、匹配的小灯泡和灯座、两根导线、开关。

1. **预测：** 在交互页或纸上画出能使灯泡发光的闭合回路，圈出可能断开的地方。
2. **操作：** 先在交互页切换开关；有器材时再连接电池、开关和灯泡，闭合后再断开开关。
3. **观察：** 记录灯泡何时发光；沿导线逐段指出是否存在完整回路。
4. **解释：** 用“闭合/断开、电压、电荷定向移动、能量转化”讲出原因。

**安全：** 仅用低压电池盒和匹配灯泡；不要把导线直接跨接电池两端。短路只看图并讨论风险，不实际搭建。

## 规律总结

**电源提供电压，闭合回路让电荷持续定向移动；灯泡转化电能，电荷并没有被消耗。**

## 家教追问

- 你能沿着导线完整地走一圈，指出回路在哪里闭合吗？
- 灯泡发光时，哪一种东西被转化了？哪一种没有被“用掉”？
