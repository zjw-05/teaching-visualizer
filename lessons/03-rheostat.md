# 滑动变阻器怎样改变电流？

**建议用时：** 15–20 分钟　｜　**核心问题：** 滑片移动时，哪一段电阻丝接入电路？

## 核心问题与误区

常见误区：只记“滑片向右，电流变大/变小”，却没看接了哪两个端子。滑片向哪边移动本身不能决定电阻变化。

初中模型：在电压基本不变时，串联电路接入的总电阻增大，电流减小；接入电阻丝的有效长度越长，电阻通常越大。灯的亮度随电流变化趋势改变，但实际亮度也受灯泡和电源影响。

## 一页理解图

以下示意：电路接在滑片 P 和右端 B，左端 A 不接。此接法下，有效电阻丝是 P 到 B 这一段。

```text
电阻丝： A ===================== B
                    ↑
                    P（滑片）
接入电路： P ──────── B

P 向左 → P到B变长 → 接入电阻变大 → 电流减小 → 灯趋于变暗
P 向右 → P到B变短 → 接入电阻变小 → 电流增大 → 灯趋于变亮
```

换成滑片 P 和左端 A 接入时，趋势会相反。**先找滑片和哪个固定端接入，再判断有效长度。**

## 先猜一猜

1. 若接入的是 P 与 B，滑片向左时，有效电阻丝变长还是变短？接下来电流怎样变化？  
   **听什么：** 变长 → 电阻增大 → 电流减小 → 灯趋于变暗。
2. 若把固定端从 B 换到 A，滑片仍向左，结果还一样吗？  
   **听什么：** 不一样；P 到 A 变短，接入电阻减小，电流增大，灯趋于变亮。

## 动手验证

**优先材料：** 低压电源、额定匹配的小灯泡、滑动变阻器、开关、导线。若没有滑动变阻器，可用纸上滑片模型；铅笔芯实验只在教师确认导电性、灯泡参数和接线后进行，结果不一定稳定。

1. **预测：** 按示意图标出接入的两个端子，画出有效电阻丝，并预测滑片移动方向对应的变化链条。
2. **操作：** 在开关闭合前，将滑片放在接入电阻较大的位置；按规范将变阻器串联接入。闭合后缓慢移动滑片观察。
3. **观察：** 记录滑片位置、有效长度和灯泡亮度的相对变化；再断电，把固定端改接另一端，先预测后验证。
4. **解释：** 每次完整说出“接入长度 → 电阻 → 电流 → 亮度”的因果链。

**安全：** 仅用低压教学电源和匹配器材；变阻器必须按串联方式接入，不能只接两个固定端或形成电源短路。若灯泡异常变亮、元件发热或电池发热，立即断开。不要用市电。铅笔芯替代实验效果取决于材料和接触，不作定量结论。

## 规律总结

**滑动变阻器靠改变滑片与已连接固定端之间的有效电阻丝长度来改变电阻；判断方向必须先看接线端子。**
